RGB Color Picker Helper

rgb(236, 72, 153)

Pick a color to copy raw RGB values

1. Program Structure

setup() : Runs once at start

draw() : Loops continuously (~60 times/sec)

createCanvas(w, h) : Sets width & height in pixels

// Setup & Draw Starter Loop function setup() { createCanvas(400, 400); } function draw() { background(220); }

2. Color & Style

background(r, g, b) : Canvas background color

fill(r, g, b) : Shape inner fill color

noFill() : Disables shape interior fill

stroke(r, g, b) : Outline color

noStroke() : Removes shape outline

strokeWeight(pixels) : Thickness of stroke line

// Example RGB Colors & Lines background(30, 40, 60); fill(255, 100, 150); stroke(255, 255, 255); strokeWeight(3);

3. 2D Shapes

ellipse(x, y, w, h) : Oval at center (x,y)

rect(x, y, w, h) : Rectangle from top-left (x,y)

line(x1, y1, x2, y2) : Line connecting two points

triangle(x1, y1, x2, y2, x3, y3) : 3 corner points

// Example Shapes ellipse(200, 200, 80, 80); rect(50, 50, 100, 60); line(0, 0, 400, 400);

4. Interactive Mouse Variables

mouseX : Current horizontal mouse coordinate

mouseY : Current vertical mouse coordinate

pmouseX : Previous mouse X coordinate

pmouseY : Previous mouse Y coordinate

mouseIsPressed : True when mouse button held

width : Width of canvas in pixels

height : Height of canvas in pixels

// Interactive Circle Following Mouse ellipse(mouseX, mouseY, 40, 40);

5. Custom Variables

let name = value; : Create a variable

x = x + 2; : Animate by incrementing

// Variable Animation Example let circleX = 50; function draw() { background(220); ellipse(circleX, 200, 50, 50); circleX = circleX + 2; }

6. Conditionals (If Statements)

if (condition) { ... } : Run code if true

else { ... } : Run fallback code if false

// Change Color on Mouse Press if (mouseIsPressed) { fill(255, 0, 0); } else { fill(0, 0, 255); }

7. For Loops

for (start; condition; step) { ... }

Repeats shapes or patterns in a row

// Draw 5 Circles across Canvas for (let i = 50; i < 400; i += 70) { ellipse(i, 200, 40, 40); }
